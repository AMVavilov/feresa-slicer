# Feresa Slicer Account Deletion / Удаление учётной записи Feresa Slicer

Last updated: August 21, 2026

## English

Feresa Slicer is published on Google Play by **make shop**. The app does not
create or operate a separate Feresa Slicer account. Optional profile
synchronization uses an account provided and operated by the independent
Orca Cloud service.

### Delete local Feresa Slicer data

1. Open the app settings and sign out of Orca Cloud. This removes the locally
   saved Orca Cloud session and cached profiles.
2. Remove any manually saved printer connection in the Printer section if you
   want to delete it without uninstalling the app.
3. Uninstall Feresa Slicer to remove the remaining private application data
   from the device. Android backup is disabled for the app.

Signing out or uninstalling Feresa Slicer does not delete the independent
Orca Cloud account or data stored by Orca Cloud.

### Delete the Orca Cloud account and cloud data

1. Open <https://cloud.orcaslicer.com/> and sign in to the same Orca Cloud
   account used in Feresa Slicer.
2. Open **User settings** in the Orca Cloud navigation.
3. In the **Danger Zone** section, choose **Delete account**.
4. Review the warning and confirm deletion in Orca Cloud.

According to the Orca Cloud documentation, this permanently removes the Orca
Cloud account and related Orca Cloud records, including profiles, shared
bundles, subscriptions, and other linked data. Official instructions:
<https://cloud.orcaslicer.com/wiki/#delete-account>.

Feresa Slicer and make shop do not control Orca Cloud and cannot complete the
provider's account-deletion confirmation on a user's behalf. Deleting an Orca
Cloud account does not delete the user's Google or GitHub identity-provider
account.

Questions about Feresa Slicer local-data deletion can be submitted at
<https://github.com/AMVavilov/feresa-slicer/issues>.

## Русский

Feresa Slicer публикуется в Google Play разработчиком **make shop**. Приложение
не создаёт отдельную учётную запись Feresa Slicer и не управляет ею. Для
необязательной синхронизации профилей используется учётная запись независимого
сервиса Orca Cloud.

### Удаление локальных данных Feresa Slicer

1. Откройте настройки приложения и выйдите из Orca Cloud. Сохранённая на
   устройстве сессия Orca Cloud и локальный кэш профилей будут удалены.
2. Если нужно удалить сохранённое подключение к принтеру без удаления
   приложения, удалите его в разделе «Принтер».
3. Удалите Feresa Slicer с устройства, чтобы очистить остальные данные в
   закрытом хранилище приложения. Резервное копирование Android для приложения
   отключено.

Выход из Orca Cloud или удаление Feresa Slicer не удаляет независимую учётную
запись Orca Cloud и данные, которые хранятся в Orca Cloud.

### Удаление учётной записи и облачных данных Orca Cloud

1. Откройте <https://cloud.orcaslicer.com/> и войдите в ту же учётную запись
   Orca Cloud, которая использовалась в Feresa Slicer.
2. Откройте **User settings** в меню Orca Cloud.
3. В разделе **Danger Zone** выберите **Delete account**.
4. Прочитайте предупреждение и подтвердите удаление в Orca Cloud.

Согласно документации Orca Cloud, это безвозвратно удаляет учётную запись и
связанные с ней данные Orca Cloud, включая профили, опубликованные наборы,
подписки и другие связанные данные. Официальная инструкция:
<https://cloud.orcaslicer.com/wiki/#delete-account>.

Feresa Slicer и make shop не управляют Orca Cloud и не могут подтвердить
удаление учётной записи у провайдера от имени пользователя. Удаление учётной
записи Orca Cloud не удаляет учётную запись Google или GitHub, использованную
для входа.

Вопросы об удалении локальных данных Feresa Slicer можно отправить по адресу
<https://github.com/AMVavilov/feresa-slicer/issues>.
